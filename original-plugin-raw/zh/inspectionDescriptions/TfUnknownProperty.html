报告块中的未知属性。

该检查仅在 Terraform 或 OpenTofu 目录已初始化（即已运行 terraform init 或 tofu init）的情况下才可用，以便 IDE 可以获取提供程序元数据。

问题示例：


resource "awscc_appflow_flow" "aws_flow1" {
  flow_name          = ""
  source_flow_config = ""
  trigger_config     = ""
  destination_flow_config_list {}
  tasks {}
  test = ""
}

在此示例中，块中的 test 属性未知。

更正示例：


resource "awscc_appflow_flow" "aws_flow1" {
  flow_name          = ""
  source_flow_config = ""
  trigger_config     = ""
  destination_flow_config_list {}
  tasks {}
}
