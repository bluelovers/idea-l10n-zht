报告对 sort.Slice 的调用，其中比较函数仅比较带有 < 运算符的元素。

在这些情况中，您可以将 sort.Slice 替换为 slices.Sort，后者会直接对切片进行排序，并移除基于索引的比较函数。

示例：


func SortInts(xs []int) {
	sort.Slice(xs, func(i, j int) bool { return xs[i] < xs[j] })
}

要修正代码，请使用将 sort.Slice 调用替换为 slices.Sort 快速修复。

在应用快速修复后：


func SortInts(xs []int) {
	slices.Sort(xs)
}

如果比较函数实现了自定义排序，请改用 slices.SortFunc。
