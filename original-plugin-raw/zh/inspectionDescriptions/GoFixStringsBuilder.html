报告对标准库类型进行基于索引的循环，其中循环体仅通过索引（如 x.At(i)）访问元素。

一些标准库类型现在提供迭代器方法，使您能够直接遍历元素。 这样便无需进行索引算术运算，使循环意图更加明确。

示例：


func Join(parts []string, sep string) string {
	var out string
	for i, p := range parts {
		if i > 0 {
			out += sep
		}
		out += p
	}
	return out
}

要修正代码，请使用将 string += string 替换为 strings.Builder 快速修复。

在应用快速修复后：


func Join(parts []string, sep string) string {
	var out strings.Builder
	for i, p := range parts {
		if i > 0 {
			out.WriteString(sep)
		}
		out.WriteString(p)
	}
	return out.String()
}
