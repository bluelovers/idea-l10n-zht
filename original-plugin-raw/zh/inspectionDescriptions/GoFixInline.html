报告对标有 //go:fix inline 的函数或常量的引用。

//go:fix inline 指令表示应重写调用方和引用，以使用声明体。 这有助于您逐步淘汰已弃用的包装器和别名，而无需手动扫描。

示例：


// 已弃用：优先使用 Pow(x, 2)。
//
//go:fix inline
func Square(x int) int { return Pow(x, 2) }

func Areas(sides []int) []int {
    out := make([]int, len(sides))
    for i, s := range sides {
        out[i] = Square(s)
    }
    return out
}

要修正代码，请使用内联调用 inline.Square 快速修复。

在应用快速修复后：


func Areas(sides []int) []int {
	out := make([]int, len(sides))
	for i, s := range sides {
		out[i] = Pow(s, 2)
	}
	return out
}

可对常量使用相同的指令，以重写对常量值或别名目标的引用。
