报告检查列表、数组或字符串是否不为空后返回第一个元素或 null 的 if 表达式。

使用 firstOrNull() 可以使代码更简洁、更符合惯用法。

该快速修复会将整个 if 表达式替换为 firstOrNull()。

示例：


  fun firstChild(children: List<String>): String？ {
      return if (children.isNotEmpty()) {
          children[0]
      } else {
          null
      }
  }

在应用快速修复后：


  fun firstChild(children: List<String>): String？ {
      return children.firstOrNull()
  }
