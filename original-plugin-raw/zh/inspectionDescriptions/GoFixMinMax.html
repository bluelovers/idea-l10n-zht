语法更新：将条件赋值替换为 min 或 max。

报告将两个值之一赋给同一变量，并且可被替换为内置 min 或 max 函数（Go 1.21 或更高版本）的 if 语句。

使用 min 和 max 可以明确意图并减少分支代码。

使用 max 的示例：


func MaxInt(a, b int) int {
	var m int
	if a > b {
		m = a
	} else {
		m = b
	}
	return m
}

要修正代码，请使用将 if 语句替换为 max 快速修复。

在应用快速修复后：


func MaxInt(a, b int) int {
	var m int
	m = max(a, b)
	return m
}

使用 min 的示例：


func ClampHigh(x, hi int) int {
	var out int
	if x > hi {
		out = hi
	} else {
		out = x
	}
	return out
}

要修正代码，请使用将 if 语句替换为 min 快速修复。

在应用快速修复后：


func ClampHigh(x, hi int) int {
	var out int
	out = min(x, hi)
	return out
}
