检测 Gradle 构建脚本中旧版 apply 插件方法的用法。

如果插件是核心插件，或来源于 gradlePluginPortal，则提供一个快速修复，将旧版语法转换为首选的 plugins 块语法。 buildscript 块将被自动修改，以移除冗余的依赖项，如果该块为空，也会被移除。

核心插件示例：


apply(plugin = "java") // 高亮显示此行

在应用快速修复后：


plugins {
    id("java")
}

外部插件示例：


buildscript {
    repositories {
        gradlePluginPortal()
    }

    dependencies {
        classpath("com.google.protobuf:com.google.protobuf.gradle.plugin:0.9.4")
    }
}

apply(plugin = "com.google.protobuf") // 报告此行

在应用快速修复后：


plugins {
    id("com.google.protobuf").version("0.9.4")
}

此处介绍了最佳做法。
