报告形式为 for i := 0; i < n; i++，可被替换为 for i := range n 的三子句 for 循环（Go 1.22 或更高版本）。

对整数使用 range 可以确保意图清晰，并移除样板循环控制代码。

示例：


func Sum(n int) int {
	total := 0
	for i := 0; i < n; i++ {
		total += i
	}
	return total
}

要修正代码，请使用将 for 循环替换为 range n 快速修复。

在应用快速修复后：


func Sum(n int) int {
	total := 0
	for i := range n {
		total += i
	}
	return total
}
