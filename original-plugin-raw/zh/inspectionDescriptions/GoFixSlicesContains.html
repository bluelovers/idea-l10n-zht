通过将每个元素与 == 进行比较来报告检查切片是否包含值的循环。

对于可比较的元素类型，slices.Contains 会在一次调用中执行相同的检查。

示例：


func HasInt(xs []int, target int) bool {
	for _, x := range xs {
		if x == target {
			return true
		}
	}
	return false
}

要修正代码，请使用通过调用 slices.Contains 替换循环快速修复。

在应用快速修复后：


func HasInt(xs []int, target int) bool {
	return slices.Contains(xs, target)
}
