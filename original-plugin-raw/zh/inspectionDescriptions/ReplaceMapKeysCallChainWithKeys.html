报告映射接收器上的 map { it.key }.toSet() 调用链，这些调用链可被替换为 keys。

注意：尽管此转换有利于可读性和性能，因为它可以避免不必要的中间集合，但它也可能会更改调用语义，因为 keys 返回的是映射的 keys 的只读视图，而原始的调用链会创建 keys 的副本。

该快速修复会将调用链替换为映射的 keys 属性。

示例：


  fun test(steps: Map<String, Int>) {
      steps.map { it.key }.toSet()
  }

在应用快速修复后：


  fun test(steps: Map<String, Int>) {
      steps.keys
  }
