报告使用 strings.Index 来查找分隔符然后手动对字符串进行切片的代码。

strings.Cut 在分隔符的第一个实例附近拆分字符串，并返回前缀、后缀和指示是否找到分隔符的布尔值。

示例：


func SplitKV(s string) (key, value string, ok bool) {
	i := strings.Index(s, "=")
	if i < 0 {
		return s, "", false
	}
	return s[:i], s[i+1:], true
}

要修正代码，请使用使用 strings.Cut 简化 strings.Index 调用快速修复。

在应用快速修复后：


func SplitKV(s string) (key, value string, ok bool) {
	before, after, ok0 := strings.Cut(s, "=")
	if !ok0 {
		return s, "", false
	}
	return before, after, true
}
