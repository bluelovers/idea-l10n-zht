报告冗余且可被替换为局部变量的 private 字段。

如果一个字段的所有局部用法都紧跟对该字段的赋值，则可以将该字段替换为一个或多个局部变量。

示例：


  class DeskLamp {
    private boolean on = false;

    boolean pressButton() {
      on = true;
      return on;
    }
  }

在应用快速修复后：


  class DeskLamp {
    boolean pressButton() {
      boolean on = true;
      return on;
    }
  }
