报告可以从上下文中推断出来并替换为 var 的局部变量类型。

示例：


  void test(InputStream s) {
    try (InputStream in = s) {}
  }

应用修正后：


  void test(InputStream s) {
    try (var in = s) {}
  }

使用仅当变量类型可通过初始值设定项明确判断时报告复选框，仅报告使用新表达式、类型转换或字面量初始化的变量类型。

示例：


  int codePointAt = "hello".codePointAt(1); // 不报告
  Random random = new Random();           // 报告
  String s = (String)object;         // 报告
