报告可能导致意外行为的配置错误的 @defer 块触发器。

该检查发现以下问题：

  • immediate 触发器会使其他触发器变得多余
  • 使用 immediate 时，预提取触发器没有任何作用
  • 预提取大于或等于主定时器延迟的定时器延迟
  • 预提取触发器与主触发器匹配，没有任何优势

示例： 


@defer (on immediate; on hover) {
  <!-- 'hover' 触发器冗余 -->
}

@defer (on timer(1000); prefetch on timer(2000)) {
  <!-- 预提取不会在主触发器之前运行 -->
}

@defer (on interaction(btn); prefetch on interaction(btn)) {
  <!-- 预提取没有任何优势 -->
}
