报告 //go:build 和 // +build 注释中的无效 Go 构建约束。

该检查会验证构建约束是否放置正确，文件是否最多有一个 //go:build 指令，以及 //go:build 表达式是否有效。

对于旧版 // +build 注释，该检查会报告无效的约束标记，例如双重否定或不受支持的字符。

如果同时存在 //go:build 和 // +build 注释，它们必须定义相同的构建约束。

该检查不提供自动快速修复。

示例：


//go:build linux
// +build darwin

package buildtag

//go:build amd64

代码包含不匹配的 //go:build 和 // +build 约束，以及放置错误的 //go:build 指令。
