报告等同于 Math.clamp() 的 Math.max() 和 Math.min() 组合。

示例： 


int min = 5, max = 10;
/*之前*/ input = Math.max(Math.min(max, input), min);
/*之后*/  input = Math.clamp(input, min, max);

默认情况下，仅当可以静态证明 min 小于或等于 max 时，才会显示该检查。 这样做是为了避免因语义更改而导致的任何 IllegalArgumentException。 如果您仍希望显示检查，可以启用即使下限可能高于上限也发出警告选项。
