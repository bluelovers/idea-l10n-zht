報告未遵循樣式指南中所建議順序的修飾符。 如果存在註解和/或上下文參數，則證明修飾符位於它們後面，並且註解位於上下文參數前面。

對修飾符排序快速修復可用於自動修正程式碼。

範例：


  private inline fun correctOrder(f: () -> Unit) {} // <== Ok

  infix private fun Int.wrongOrder(expr: Int) {} // <== 順序錯誤，快速修復會將修飾符修正為 "private infix"


    @Deprecated("message")
    context(str: String)
    private fun doThis() { } // <== Ok


    context(str: String)
    @Deprecated("message")
    fun doThis() { } // <== wrong order, quick-fix moves the annotation to the top
