報告 Kotlin 對可被取代為 enumEntries() 的 enumValues() 方法的呼叫。

使用 enumEntries() 可能會提高程式碼的性能。

該快速修復會將 enumValues() 取代為 enumEntries()。

更多詳細資訊：KT-61120 為 Enum.values() 提供了現代且高效的替代

注意：enumEntries() 的返回值類型與 enumValues() 的返回值類型不同（EnumEntries<T> 繼承自 List<T>，而不是 Array<T>）。 因此，在某些情況下，快速修復會插入額外的 .toTypedArray() 轉換，以避免破壞程式碼，但在大多數情況下，取代將在沒有該轉換的情況下完成（例如，在 for 迴圈中）。

範例：


    enum class Version {
        V1, V2
    }

    enumValues().values().forEach { /* .. */ }
    val firstVersion = enumValues()[0]
    functionExpectingArray(enumValues())

在套用快速修復後：


    enum class Version {
        V1, V2
    }

    enumEntries().forEach { /* .. */ }
    val firstVersion = enumEntries()[0]
    functionExpectingArray(enumEntries().toTypedArray())
