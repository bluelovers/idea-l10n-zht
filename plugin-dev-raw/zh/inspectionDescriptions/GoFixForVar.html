報告 for range 迴圈內部的冗餘變數隱藏，例如 x := x，它之前被用於捕獲 Goroutine 或閉包的迴圈變數。

從 Go 1.22 開始，每次 for range 迭代都使用一個新的迴圈變數。 因此，額外的 x := x 賦值不再改變行為，而且可以移除。

範例：


for _, x := range xs {
    x := x
    go func() { done <- x }()
}

為了簡化程式碼，請使用移除不必要的宣告快速修復。

在套用快速修復後：


for _, x := range xs {
    go func() { done <- x }()
}
