報告繼承自兩個基類別並且這兩個基類別具有不相容的不相交基 (PEP 800) 的類別。

當一個類別帶有 @typing.disjoint_base 裝飾器或具有非空的 __slots__ 特性（包括使用 slots=True 建立的資料類別）時，該類就是一個不相交基。 許多內建類型，例如 int、str、float、tuple、list、dict 等，都是不相交基。

如果兩個類別各自追溯到不同、不相關的不相交基，它們就不能共享一個公共子類別 — 由於記憶體布局不相容，Python 在執行時會引發 TypeError。

範例：


class A:
    __slots__ = ('x',)

class B:
    __slots__ = ('y',)

class C(A, B):  # 錯誤：A 和 B 具有不相容的不相交基
    pass

共享公共不相交基上級的類別（例如，同一個槽類別的兩個子類別）不會被標記。
