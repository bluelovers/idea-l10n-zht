對陣列呼叫 toString() 返回的是物件在記憶體中的地址，而不是陣列內容的字串表示。 這幾乎從來不是您希望得到的結果。

要正確獲取陣列的字串表示，請使用：

  • contentToString()（用於線性陣列）
  • contentDeepToString()（用於多維陣列）

範例（顯式 toString）：


  fun main() {
      val a = arrayOf(1, 2, 3)
      val s = a.toString() // 錯誤
  }

在套用快速修復後：


  fun main() {
      val a = arrayOf(1, 2, 3)
      val s = a.contentToString() // 正確
  }

範例（字串模板中的隱式 toString）：


  fun main() {
      val a = arrayOf(1, 2, 3)
      println("Array: $a") // 錯誤 - 列印地址
  }

在套用快速修復後：


  fun main() {
      val a = arrayOf(1, 2, 3)
      println("Array: ${a.contentToString()}") // 正確 - 列印 [1, 2, 3]
  }

範例（多維陣列）：


  fun main() {
      val a2d = arrayOf(arrayOf(1, 2), arrayOf(3, 4))
      val s = a2d.toString() // 錯誤
  }

在套用快速修復後：


  fun main() {
      val a2d = arrayOf(arrayOf(1, 2), arrayOf(3, 4))
      val s = a2d.contentDeepToString() // 正確 - 列印 [[1, 2], [3, 4]]
  }
