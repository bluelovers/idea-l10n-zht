報告遍歷 strings.Split 或 strings.Fields 的迴圈。

這些函式會分配一個僅用於迭代的子字串切片。 在 Go 1.24 及更高版本中，strings.SplitSeq 和 strings.FieldsSeq 返回的迭代器可以直接生成每個片段，而無需分配中間切片。

範例：


func CountCSV(s string) int {
	n := 0
	for p := range strings.SplitSeq(s, ",") {
		if p != "" {
			n++
		}
	}
	return n
}

要修正程式碼，請使用將 Split 取代為 SplitSeq 快速修復。

在套用快速修復後：


func CountWords(s string) int {
	n := 0
	for _, w := range strings.Fields(s) {
		_ = w
		n++
	}
	return n
}

範例：


func CountWords(s string) int {
	n := 0
	for w := range strings.FieldsSeq(s) {
		_ = w
		n++
	}
	return n
}

要修正程式碼，請使用將 Fields 取代 FieldsSeq 快速修復。

在套用快速修復後：


n := 0
for w := range strings.FieldsSeq(s) {
    _ = w
    n++
}
