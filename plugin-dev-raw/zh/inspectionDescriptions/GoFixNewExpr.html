報告對返回參數地址（例如 IntPtr(x) 會返回 &x）且可被取代為 new(...) 的輔助函式的呼叫。

在 Go 1.26 中，new 可以直接接收值。 這樣便可在不使用包裝器函式的情況下建立指向字面量和其他值的指針。

範例：


type Config struct {
    Retries *int
    Label   *string
}

func Default() Config {
    return Config{
        Retries: IntPtr(3),
        Label:   StringPtr("default"),
    }
}

要修正程式碼，請使用將 foo(x) 簡化為 new(x) 快速修復。

在套用快速修復後：


func Default() Config {
    return Config{
        Retries: new(3),
        Label:   new("default"),
    }
}
