報告使用 IElementType 或其子類型初始化的實例欄位。

IElementType 實例代表 IntelliJ 平台的詞法分析器/解析器基礎架構中的令牌類型，應定義為 static 常數以確保它們為單例。 定義為實例欄位時，會為每個類別實例建立一個新的 IElementType 實例。 所有此類別實例都會註冊到 IElementType 內部存儲中，並保留在那裡，直到套用關閉。 目前，該基礎架構僅允許存儲約 16000 種元素類型，並不是很多。

該檢查建議在 Java 中將實例欄位轉換為 static 常數，或者在 Kotlin 中將它們移至伴生物件。

錯誤模式 (Java)：


class MyTokens {
  // 為每個 MyTokens 實例建立的新 IElementType
  IElementType myToken = new IElementType("MY_TOKEN");
}

正確模式 (Java)：


class MyTokens {
  // 跨所有實例共享的單例 IElementType
  static final IElementType MY_TOKEN = new IElementType("MY_TOKEN");
}

錯誤模式 (Kotlin)：


class MyTokens {
  // 為每個 MyTokens 實例建立的新 IElementType
  val myToken = IElementType("MY_TOKEN")
}

正確模式 (Kotlin)：


class MyTokens {
  companion object {
    // 跨所有實例共享的單例 IElementType
    val MY_TOKEN = IElementType("MY_TOKEN")
  }
}

或者在 Kotlin 中，令牌類型可以定義為頂層宣告或物件宣告： 


// 頂層常數
private val MY_TOKEN = IElementType("MY_TOKEN")

// 或者在物件中
object MyTokens {
  val MY_TOKEN = IElementType("MY_TOKEN")
}
