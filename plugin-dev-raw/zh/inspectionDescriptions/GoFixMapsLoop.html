報告複製映射或者收集其鍵或值，並且可被取代為 maps.Copy、maps.Keys 或 maps.Values 的迴圈。

這些輔助函式會直接表達意圖，並減少樣板程式碼。

使用 copy 的範例：


func Copy(dst, src map[string]int) {
	for k, v := range src {
		dst[k] = v
	}
}

要修正程式碼，請使用將 m[k]=v loop 取代為 maps.Copy 快速修復。

在套用快速修復後：


func Copy(dst, src map[string]int) {
	maps.Copy(dst, src)
}
