報告基於位置的解構宣告，這些宣告使用自訂 componentN 函式，並且需要針對基於名稱的解構進行遷移。

啟用新的基於名稱的解構後，圓括號 (x, y) 將用於基於名稱的解構，而方括號 [x, y] 則應當用於基於位置的解構。

該檢查會在以下情況下發出警告：

  • 解構非資料類別（所有組件都是自訂組件）
  • 解構條目比主建構函式參數更多的資料類別（額外的組件為自訂組件）

範例：


  val (x, y) = listOf(1, 2) // 警告：使用自訂 componentN
  for ((key, value) in mapOf(1 to "one")) { } // 沒有警告：key 和 value 為 Map.Entry 屬性

  data class Person(val name: String, val age: Int) {
      operator fun component3(): String = name + age
  }
  val (name, age, rendered) = Person("John", 30) // 警告：component3 為自訂

此檢查屬於基於名稱的解構的遷移計劃的一部分。
