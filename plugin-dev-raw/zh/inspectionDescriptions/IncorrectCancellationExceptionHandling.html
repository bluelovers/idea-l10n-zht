報告 ProcessCanceledException 和 CancellationException 處理不正確的情況。

不得以任何方式捕獲、吞下、記錄*或處理 ProcessCanceledException 及其繼承者。 相反，必須將其重新拋出，以便 IntelliJ Platform 基礎架構能夠對其進行正確處理。

在協程上下文中不得以任何方式捕獲、吞下、記錄*或處理 CancellationException。 相反，必須將其重新拋出，以便協程基礎架構能夠對其進行正確處理。

*該檢查會報告在任何執行上下文中記錄這些異常。

該檢查會報告顯式 ProcessCanceledException（包括繼承者）和 CancellationException 捕獲，以及對覆蓋取消異常的 RuntimeException、Exception 和 Throwable 的捕獲。

範例：

ProcessCanceledException:


// bad:
try {
  // ...
} catch (ProcessCanceledException e) { // 不應吞下異常
}

// 錯誤：
try {
  // ...
} catch (ProcessCanceledException e) {
  LOG.error("Error occurred", e); // 不應記錄異常
  throw e;
}


// 正確：
try {
  // ...
} catch (ProcessCanceledException e) {
  // 其他動作
  throw e;
}

CancellationException:


// bad:
cs.launch {
  try {
    // ...
  } catch (e: CancellationException) { // 不應吞下異常
  }
}

// 錯誤：
suspend fun suspendingFunction() {
  try {
    // ...
  } catch (ProcessCanceledException e) {
    LOG.error("Error occurred", e); // 不應記錄異常
    throw e;
  }
}


// 正確：
cs.launch {
  try {
    // ...
  } catch (ProcessCanceledException e) {
    // additional actions
    throw e;
  }
}

如需了解詳情，請參閱 IntelliJ 平台延伸模組 SDK 文檔中的背景程序取消。

註：檢查在測試源中被停用。
