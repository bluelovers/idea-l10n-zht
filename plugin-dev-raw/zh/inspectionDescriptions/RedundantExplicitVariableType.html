報告可以從上下文中推斷出來並取代為 var 的區域變數類型。

範例：


  void test(InputStream s) {
    try (InputStream in = s) {}
  }

套用修正後：


  void test(InputStream s) {
    try (var in = s) {}
  }

使用僅當變數類型可通過初始設定式明確判斷時報告複選框，僅報告使用新表達式、類型轉換或字面量初始化的變數類型。

範例：


  int codePointAt = "hello".codePointAt(1); // 不報告
  Random random = new Random();           // 報告
  String s = (String)object;         // 報告
