檢測 Gradle 建置腳本中舊版 apply 延伸模組方法的用法。

如果延伸模組是核心延伸模組，或來源於 gradlePluginPortal，則提供一個快速修復，將舊版語法轉換為首選的 plugins 塊語法。 buildscript 塊將被自動修改，以移除冗餘的相依項，如果該塊為空，也會被移除。

核心延伸模組範例：


apply(plugin = "java") // 醒目提示顯示此行

在套用快速修復後：


plugins {
    id("java")
}

外部延伸模組範例：


buildscript {
    repositories {
        gradlePluginPortal()
    }

    dependencies {
        classpath("com.google.protobuf:com.google.protobuf.gradle.plugin:0.9.4")
    }
}

apply(plugin = "com.google.protobuf") // 報告此行

在套用快速修復後：


plugins {
    id("com.google.protobuf").version("0.9.4")
}

此處介紹了最佳做法。
