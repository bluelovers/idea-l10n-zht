報告將 unsafe.Pointer 轉換為 uintptr、加上偏移量，然後將結果轉換回 unsafe.Pointer 的指針算術運算。

這種模式可能不安全，因為 uintptr 值在轉換和下次指針使用之間可能會被垃圾收集器觀察到。 在 Go 1.17 及更高版本中，unsafe.Add 直接表示相同的動作。

範例：


func Offset(p unsafe.Pointer, n int) unsafe.Pointer {
	return unsafe.Pointer(uintptr(p) + uintptr(n))
}

要修正程式碼，請使用使用 unsafe.Add 簡化指針加法快速修復。

在套用快速修復後：


func Offset(p unsafe.Pointer, n int) unsafe.Pointer {
	return unsafe.Add(p, n)
}
