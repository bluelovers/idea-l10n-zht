檢測是否修改了某些 SSL 參數欄位，這些修改可能會限制後量子加密的合規性。

某些修改可能會妨礙後量子加密的使用。 這包括以下欄位：

  • algorithmConstraints
  • applicationProtocols
  • cipherSuites
  • namedGroups
  • protocols
  • signatureSchemes

範例： 


val sslParameters = SSLParameters()
// 錯誤：永遠不會使用後量子簽名方案
sslParameters.signatureSchemes = listOf("ed25519")
