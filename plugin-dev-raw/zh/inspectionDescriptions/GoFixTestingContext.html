報告使用 context.WithCancel(context.Background()) 建立可取消上下文並立即推遲 cancel()的測試程式碼。

在 Go 1.24 及更高版本中，t.Context() 會返回一個在測試結束時自動取消的上下文。 這樣一來，手動 WithCancel 和 defer cancel() 對就變得冗餘。

範例：


func TestSomething(t *testing.T) {
	ctx, cancel := context.WithCancel(context.Background())
	defer cancel()

	if err := work(ctx); err != nil {
		t.Fatal(err)
	}
}

要修正程式碼，請使用將 context.WithCancel 取代為 t.Context 快速修復。

在套用快速修復後：


func TestSomething(t *testing.T) {
	ctx := t.Context()

	if err := work(ctx); err != nil {
		t.Fatal(err)
	}
}
