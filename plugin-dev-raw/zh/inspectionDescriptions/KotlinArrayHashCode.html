對陣列呼叫 hashCode() 會返回身份雜湊程式碼，而不是基於陣列內容的雜湊。 這幾乎從來不是您希望得到的結果。

要正確計算陣列的雜湊程式碼，請使用：

  • contentHashCode()（用於線性陣列）
  • contentDeepHashCode()（用於多維陣列）

範例：


  fun main() {
      val a1 = arrayOf<Any>()
      val hashcode = a1.hashCode() // 錯誤
  }

在套用快速修復後：


  fun main() {
      val a1 = arrayOf<Any>()
      val hashcode = a1.contentHashCode() // 正確
  }
