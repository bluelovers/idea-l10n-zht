報告形式為 for i := 0; i < n; i++，可被取代為 for i := range n 的三子句 for 迴圈（Go 1.22 或更高版本）。

對整數使用 range 可以確保意圖清晰，並移除樣板迴圈控制程式碼。

範例：


func Sum(n int) int {
	total := 0
	for i := 0; i < n; i++ {
		total += i
	}
	return total
}

要修正程式碼，請使用將 for 迴圈取代為 range n 快速修復。

在套用快速修復後：


func Sum(n int) int {
	total := 0
	for i := range n {
		total += i
	}
	return total
}
