報告可被取代為 elvis 運算符和 error(...) 的非 null 斷言 (!!) 呼叫。

非 null 斷言可能導致意想不到的 NPE (NullPointerException)。 將其取代為 ?: error(...) 會使失敗顯現出來，並支援整個檔案的檢查清理。

範例：


fun test(number: Int?) {
    val x = number!!
}

在套用快速修復後：


fun test(number: Int?) {
    val x = number ?: error("Expression 'number' must not be null")
}
