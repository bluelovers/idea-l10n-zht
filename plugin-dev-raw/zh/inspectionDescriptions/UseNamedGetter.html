報告 Java 程式碼中對基於 Kotlin data 類別生成的 componentN() 方法的呼叫。

Kotlin 資料類別會自動生成位置 component1()、component2() 以及類似方法，用於解構。 從 Java 中直接呼叫這些方法不穩定：索引與屬性之間的映射不直觀，且一旦屬性重新排序，這些呼叫會靜默中斷。 使用命名屬性 getter 更清晰，且重構時更安全。

範例：


  String name = person.component1();
  int age = person.component2();

在套用快速修復後：


  String name = person.getName();
  int age = person.getAge();
