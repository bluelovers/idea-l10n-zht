報告映射接收器上的 map { it.key }.toSet() 呼叫鏈，這些呼叫鏈可被取代為 keys。

注意：儘管此轉換有利於可讀性和性能，因為它可以避免不必要的中間集合，但它也可能會更改呼叫語意，因為 keys 返回的是映射的 keys 的唯讀檢視，而原始的呼叫鏈會建立 keys 的副本。

該快速修復會將呼叫鏈取代為映射的 keys 屬性。

範例：


  fun test(steps: Map<String, Int>) {
      steps.map { it.key }.toSet()
  }

在套用快速修復後：


  fun test(steps: Map<String, Int>) {
      steps.keys
  }
