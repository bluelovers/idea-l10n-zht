語法更新：將條件賦值取代為 min 或 max。

報告將兩個值之一賦給同一變數，並且可被取代為內建 min 或 max 函式（Go 1.21 或更高版本）的 if 語句。

使用 min 和 max 可以明確意圖並減少分支程式碼。

使用 max 的範例：


func MaxInt(a, b int) int {
	var m int
	if a > b {
		m = a
	} else {
		m = b
	}
	return m
}

要修正程式碼，請使用將 if 語句取代為 max 快速修復。

在套用快速修復後：


func MaxInt(a, b int) int {
	var m int
	m = max(a, b)
	return m
}

使用 min 的範例：


func ClampHigh(x, hi int) int {
	var out int
	if x > hi {
		out = hi
	} else {
		out = x
	}
	return out
}

要修正程式碼，請使用將 if 語句取代為 min 快速修復。

在套用快速修復後：


func ClampHigh(x, hi int) int {
	var out int
	out = min(x, hi)
	return out
}
