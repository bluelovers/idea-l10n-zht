報告可能導致意外行為的組態錯誤的 @defer 塊觸發器。

該檢查發現以下問題：

  • immediate 觸發器會使其他觸發器變得多餘
  • 使用 immediate 時，預提取觸發器沒有任何作用
  • 預提取大於或等於主定時器延遲的定時器延遲
  • 預提取觸發器與主觸發器符合，沒有任何優勢

範例： 


@defer (on immediate; on hover) {
  <!-- 'hover' 觸發器冗餘 -->
}

@defer (on timer(1000); prefetch on timer(2000)) {
  <!-- 預提取不會在主觸發器之前執行 -->
}

@defer (on interaction(btn); prefetch on interaction(btn)) {
  <!-- 預提取沒有任何優勢 -->
}
