通過將每個元素與 == 進行比較來報告檢查切片是否包含值的迴圈。

對於可比較的元素類型，slices.Contains 會在一次呼叫中執行相同的檢查。

範例：


func HasInt(xs []int, target int) bool {
	for _, x := range xs {
		if x == target {
			return true
		}
	}
	return false
}

要修正程式碼，請使用通過呼叫 slices.Contains 取代迴圈快速修復。

在套用快速修復後：


func HasInt(xs []int, target int) bool {
	return slices.Contains(xs, target)
}
