報告對標有 //go:fix inline 的函式或常數的參照。

//go:fix inline 指令表示應覆寫呼叫方和參照，以使用宣告體。 這有助於您逐步淘汰已棄用的包裝器和別名，而無需手動掃描。

範例：


// 已棄用：優先使用 Pow(x, 2)。
//
//go:fix inline
func Square(x int) int { return Pow(x, 2) }

func Areas(sides []int) []int {
    out := make([]int, len(sides))
    for i, s := range sides {
        out[i] = Square(s)
    }
    return out
}

要修正程式碼，請使用內聯呼叫 inline.Square 快速修復。

在套用快速修復後：


func Areas(sides []int) []int {
	out := make([]int, len(sides))
	for i, s := range sides {
		out[i] = Pow(s, 2)
	}
	return out
}

可對常數使用相同的指令，以覆寫對常量值或別名目標的參照。
