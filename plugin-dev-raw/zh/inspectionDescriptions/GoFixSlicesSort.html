報告對 sort.Slice 的呼叫，其中比較函式僅比較帶有 < 運算符的元素。

在這些情況中，您可以將 sort.Slice 取代為 slices.Sort，後者會直接對切片進行排序，並移除基於索引的比較函式。

範例：


func SortInts(xs []int) {
	sort.Slice(xs, func(i, j int) bool { return xs[i] < xs[j] })
}

要修正程式碼，請使用將 sort.Slice 呼叫取代為 slices.Sort 快速修復。

在套用快速修復後：


func SortInts(xs []int) {
	slices.Sort(xs)
}

如果比較函式實作了自訂排序，請改用 slices.SortFunc。
