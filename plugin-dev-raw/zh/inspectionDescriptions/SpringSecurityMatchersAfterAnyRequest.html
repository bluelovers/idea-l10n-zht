報告在 authorizeHttpRequests / authorizeRequests 塊中 anyRequest() 之後鏈接的請求匹配器註冊（requestMatchers、mvcMatchers、antMatchers、regexMatchers）。

anyRequest() 必須為授權鏈中的最後一個匹配器。 在它之後組態另一個匹配器會導致 Spring Security 在啟動時失敗，並出現 Can't configure requestMatchers after anyRequest。

不正確：


  http.authorizeHttpRequests(auth -> auth
    .requestMatchers("/", "/home").permitAll()
    .anyRequest().authenticated()
    .requestMatchers("/admin/**").hasRole("ADMIN")   // 報告：在 anyRequest() 之後組態
  );

正確（將 anyRequest() 移至結尾）：


  http.authorizeHttpRequests(auth -> auth
    .requestMatchers("/", "/home").permitAll()
    .requestMatchers("/admin/**").hasRole("ADMIN")
    .anyRequest().authenticated()
  );
