報告在結構體型欄位中使用 ,omitempty 的 JSON 結構體標記。

對於結構體值，,omitempty 不會省略該欄位，因為結構體值絕不會為 nil。

在 Go 1.24 及更高版本中，當結構體值為零值時，,omitzero 會省略該欄位。

注意：將 ,omitempty 取代為 ,omitzero 是一種行為改變。 如果該欄位以前一直存在，則可以省略該欄位。

範例：


type Event struct {
    CreatedAt time.Time `json:"created_at,omitempty"`
    Source    Source    `json:"source,omitempty"`
}

要修正程式碼，請執行以下動作之一：

  • 使用移除冗餘的 omitempty 標記快速修復以保持當前 JSON 輸出。
  • 使用將 omitempty 取代為 omitzero(行為改變) 快速修復以在結構體值為零時省略該欄位。

在移除標記的快速修復之後：


type Event struct {
    CreatedAt time.Time `json:"created_at"`
    Source    Source    `json:"source"`
}

在改變行為的快速修復之後：


type Event struct {
    CreatedAt time.Time `json:"created_at,omitzero"`
    Source    Source    `json:"source,omitzero"`
}
