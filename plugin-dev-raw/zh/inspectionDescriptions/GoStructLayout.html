報告通過‌重新排序欄位‌最小化‌填充‌，從而減少記憶體佔用的 ‌Go 結構體‌類型。

Go 編譯器會在結構體欄位之間插入填充位元組，以滿足對齊要求。 當欄位排序非最優時，這種‌填充可能會浪費大量記憶體，尤其是在大量分配的結構體中（切片、映射、快取）。

將欄位按‌對齊要求‌從大到小重新排序可以消除不必要的‌填充‌並減少結構體的‌記憶體佔用‌。 使用更新結構體布局快速修復可以自動套用最佳欄位順序。

範例：

type Config struct {
    Active bool     // 1 位元組 + 7 位元組填充
    Value  int64    // 8 位元組
    Flag   bool     // 1 位元組 + 7 位元組填充
}  // 共計：24 位元組，浪費了 14 位元組

在這裡，由於對齊要求，int64 欄位之間的 bool 欄位分別會產生 7 位元組的填充。 該結構體浪費了 24 位元組中的 14 位元組 (58%)。

在套用快速修復後：

type Config struct {
    Value  int64    // 8 位元組
    Active bool     // 1 位元組
    Flag   bool     // 1 位元組 + 6 位元組填充
}  // 共計：16 位元組，節省了 8 位元組

通過將最大的欄位放在最前面，兩個 bool 欄位可共用末尾的一個填充塊。 結構體的大小從 24 字節減少到 16 位元組 — 減少了 33%。
