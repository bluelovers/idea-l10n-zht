檢測到不使用委託而直接使用 lazy { ... } 的情況。

範例：


    private val x = lazy { "hello" }

    fun test() {
        printlin(x.value)
    }
如果 lazy 變數僅通過直接存取其值的方式來使用，則建議使用快速修復： 

  private val x by lazy { "hello" }

  fun test() {
        println(x)
  }

不會報告具有顯式 lazy 類型的建構，例如 


    private val x: Lazy<String> = lazy { "hello" }
因為它們被認為是有意使用的。
