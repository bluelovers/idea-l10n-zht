報告等同於 Math.clamp() 的 Math.max() 和 Math.min() 組合。

範例： 


int min = 5, max = 10;
/*之前*/ input = Math.max(Math.min(max, input), min);
/*之後*/  input = Math.clamp(input, min, max);

預設情況下，僅當可以靜態證明 min 小於或等於 max 時，才會顯示該檢查。 這樣做是為了避免因語意更改而導致的任何 IllegalArgumentException。 如果您仍希望顯示檢查，可以啟用即使下限可能高於上限也發出警告選項。
