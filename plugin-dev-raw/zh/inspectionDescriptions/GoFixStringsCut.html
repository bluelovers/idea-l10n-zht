報告使用 strings.Index 來尋找分隔符然後手動對字串進行切片的程式碼。

strings.Cut 在分隔符的第一個實例附近拆分字串，並返回前綴、後綴和指示是否找到分隔符的布林值。

範例：


func SplitKV(s string) (key, value string, ok bool) {
	i := strings.Index(s, "=")
	if i < 0 {
		return s, "", false
	}
	return s[:i], s[i+1:], true
}

要修正程式碼，請使用使用 strings.Cut 簡化 strings.Index 呼叫快速修復。

在套用快速修復後：


func SplitKV(s string) (key, value string, ok bool) {
	before, after, ok0 := strings.Cut(s, "=")
	if !ok0 {
		return s, "", false
	}
	return before, after, true
}
