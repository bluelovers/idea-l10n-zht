報告可被簡化為單個表達式的布爾 if 表達式和語句。

範例：


  fun test(): Boolean {
      if (foo()) {
         return true
      } else {
         return false
      }
  }

在套用快速修復後：


  fun test(): Boolean {
      return foo()
  }

該檢查還可以簡化其中一個分支為布爾常數的分支：


  val filterModified = if (condition) {
      someBooleanExpression
  } else {
      false
  }

在套用快速修復後：


  val filterModified = condition && someBooleanExpression
