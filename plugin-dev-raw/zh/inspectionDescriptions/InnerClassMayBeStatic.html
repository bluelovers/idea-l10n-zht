報告可以設定為 static 的內部類別。

在 Java 17 及更早版本中，非 static 內部類別包含對其封閉實例的隱式參照。 static 嵌套類別沒有此類別參照。 因此，將內部類別設為 static 可以避免出現常見的記憶體泄漏原因，並略微減少該類的每個實例使用的記憶體。

Java 18 中移除了對非 Serializable 內部類別的隱式參照。

範例：


  public class Outer {
    class Inner { // 非 static
      public void foo() {
        bar("x");
      }

      private void bar(String string) {}
    }
  }

在套用快速修復後：


  public class Outer {
    static class Inner {
      public void foo() {
        bar("x");
      }

      private void bar(String string) {}
    }
  }
