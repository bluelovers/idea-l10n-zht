報告使用 fmt.Sprintf("%s:%d", host, port) 或 fmt.Sprintf("%s:%s", host, port) 建置的地址。

對於 IPv6 主機，這種模式會中斷，因為 IPv6 地址必須用中括號括起來，如 [host]:port。 net.JoinHostPort 會為 IPv4 和 IPv6 正確設定地址格式。

範例：


addr := fmt.Sprintf("%s:%d", host, port)
return net.Dial("tcp", addr)

要修正程式碼，請使用取代為 net.JoinHostPort 快速修復。

在套用快速修復後：


addr := net.JoinHostPort(host, fmt.Sprintf("%d", port))
return net.Dial("tcp", addr)
