報告帶有普通 @Transactional 註解的 @TransactionalEventListener 方法。

一個事務事件偵聽器在原始事務的清理階段執行，該事務仍然有效，但處於未定義狀態。 因此，一般 @Transactional 在未定義的事務狀態下執行，並在執行時失敗。 只有當傳播為 REQUIRES_NEW 或 NOT_SUPPORTED，或者該方法同樣帶有 @Async 註解（它會在具有乾淨事務狀態的單獨執行緒上執行偵聽器）時，該組合才有效。

範例：


  @Component
  class MyListener {
    @Transactional // 報告：在未定義的事務狀態下執行
    @TransactionalEventListener
    void on(MyEvent event) { ... }
  }

在套用該快速修復後：


  @Component
  class MyListener {
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    @TransactionalEventListener
    void on(MyEvent event) { ... }
  }
