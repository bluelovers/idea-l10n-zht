報告 Collection 類型的 static 欄位。 雖然這不一定是問題，但靜態集合通常會導致記憶體泄漏，因此會被某些編碼標準禁止。

範例：


  public class Example {
    static List<String> list = new ArrayList<>();

  }

該檢查會忽略使用不可變、固定大小集合初始化的 final 欄位（例如 Map.of()、List.of()、Collections.emptyList()、Collections.singletonMap()）。 這些集合無法擴展，因此不會導致記憶體泄漏。

組態檢查：

  • 使用忽略弱靜態集合或映射選項可以忽略 java.util.WeakHashMap 類型的欄位。
