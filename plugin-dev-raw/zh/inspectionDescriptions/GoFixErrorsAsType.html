報告可被取代為 errors.AsType 的對 errors.As 的呼叫。

在 Go 1.26 及更高版本中，errors.AsType[T] 會直接返回符合的錯誤值。 這將移除單獨宣告的變數和傳遞給 errors.As 的指針。

範例：


func Describe(err error) string {
	var pe *PathError
	if errors.As(err, &pe) {
		return fmt.Sprintf("path error during %s", pe.Op)
	}
	return "other"
}

要修正程式碼，請使用將 errors.As 取代為 AsType[*PathError] 快速修復。

在套用快速修復後：


func Describe(err error) string {
	if pe, ok := errors.AsType[*PathError](err); ok {
		return fmt.Sprintf("path error during %s", pe.Op)
	}
	return "other"
}
