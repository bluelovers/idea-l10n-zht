報告變數名稱與資料類別的原始屬性名稱不符合的解構宣告。

範例：


  data class Product(val id: String, val productName: String)
  val (id, name) = product // 關於“name”的警告

以下是可用的快速修復：

  • 重新命名變數以符合解構屬性名稱：val (id, productName) = product
  • 使用帶方括號的位置解構：val [id, name] = product

對於像 Pair、 Triple 和 IndexedValue 這樣的標準庫類別，該檢查會建議使用位置解構語法，因為這些類型是為位置存取而不是基於名稱的符合設計的。

此檢查為即將推出的 Kotlin 語言功能更改做好程式碼準備，在此更改中，val (x, y) = e 語法將從基於位置的解構轉換為基於名稱的解構。
