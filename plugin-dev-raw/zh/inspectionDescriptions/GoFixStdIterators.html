報告對標準庫類型進行基於索引的迴圈，其中循環體僅通過索引（如 x.At(i)）存取元素。

一些標準庫類型現在提供迭代器方法，使您能夠直接遍歷元素。 這樣便無需進行索引算術運算，使迴圈意圖更加明確。

範例：


func TupleNames(t *types.Tuple) string {
	var names []string
	for i := 0; i < t.Len(); i++ {
		names = append(names, t.At(i).Name())
	}
	return strings.Join(names, ",")
}

要修正程式碼，請使用將 Len/At 迴圈取代為 Tuple.Variables 迭代快速修復。

在套用快速修復後：


func TupleNames(t *types.Tuple) string {
	var names []string
	for v := range t.Variables() {
		names = append(names, v.Name())
	}
	return strings.Join(names, ",")
}
