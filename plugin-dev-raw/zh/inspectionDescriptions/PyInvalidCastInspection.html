報告源類型和目標類型不相關的 typing.cast 呼叫。

當源類型既不是目標類型的子類型，目標類型也不是源類型的子類型時，將報告錯誤。 此類別轉換通常指示邏輯錯誤，因為一種類型的實例不能被假定為另一種類型的實例，並且 typing.cast 不會動態驗證類型。

此檢查甚至適用於理論上可能具有共同後代的類型。 例如，它將標記兩個同級類別 Left 和 Right 之間的轉換，因為它們都繼承自 Top，但彼此之間沒有直接繼承關係。

範例：


from typing import cast

# 非重疊類型 — 可能是錯誤
cast(int, "a")          # 'str' -> 'int'
cast(list[int], ["a"])  # 'list[str]' -> 'list[int]'

# 推薦的顯式逃生艙口是使用“雙重轉換”
cast(int, cast(object, "a"))  # 正確

# 合法的重疊情況
cast(int, object())    # 有效的向下轉換
cast(object, 1)        # 有效的向上轉換

# 預設情況下，會忽略泛型類型實參的變體，因此，儘管 list 是不變的，
# 也不會報告以下情況
int_list = [1, 2, 3]
cast(list[object], int_list)  # 正確

該檢查依賴於靜態類型資訊；當類型未知時，不會報告警告。

使用忽略泛型類型實參的差異選項可控制是否考慮泛型類型實參。 啟用後（預設設定），僅會按基類別比較參數化類型，因此允許進行 cast(list[object], int_list) 之類的轉換。 停用此選項還會報告只有其（不變）類型實參不同的轉換。

使用忽略 TypedDict 結構(將 TypedDict 視為 dict)選項來控制是否將 TypedDict 視為普通字典。 啟用後（預設設定），允許將 dict 轉換為 TypedDict（或反向轉換），因為 TypedDict 在執行時為 dict：


from typing import TypedDict, cast

class TD(TypedDict):
    x: int

data: dict[str, object]
cast(TD, data)  # ok

停用此選項可在字典結構與 TypedDict 不符合時報告此類別轉換。
