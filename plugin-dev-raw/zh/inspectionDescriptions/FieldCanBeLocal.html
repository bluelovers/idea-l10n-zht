報告冗餘且可被取代為區域變數的 private 欄位。

如果一個欄位的所有區域用法都緊跟對該欄位的賦值，則可以將該欄位取代為一個或多個區域變數。

範例：


  class DeskLamp {
    private boolean on = false;

    boolean pressButton() {
      on = true;
      return on;
    }
  }

在套用快速修復後：


  class DeskLamp {
    boolean pressButton() {
      boolean on = true;
      return on;
    }
  }
