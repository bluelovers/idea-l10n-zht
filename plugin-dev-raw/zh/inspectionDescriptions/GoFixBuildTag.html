報告 //go:build 和 // +build 註釋中的無效 Go 建置約束。

該檢查會驗證建置約束是否放置正確，檔案是否最多有一個 //go:build 指令，以及 //go:build 表達式是否有效。

對於舊版 // +build 註釋，該檢查會報告無效的約束標記，例如雙重否定或不受支援的字元。

如果同時存在 //go:build 和 // +build 註釋，它們必須定義相同的建置約束。

該檢查不提供自動快速修復。

範例：


//go:build linux
// +build darwin

package buildtag

//go:build amd64

程式碼包含不符合的 //go:build 和 // +build 約束，以及放置錯誤的 //go:build 指令。
