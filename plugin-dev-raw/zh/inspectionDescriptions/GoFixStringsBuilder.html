報告對標準庫類型進行基於索引的迴圈，其中循環體僅通過索引（如 x.At(i)）存取元素。

一些標準庫類型現在提供迭代器方法，使您能夠直接遍歷元素。 這樣便無需進行索引算術運算，使迴圈意圖更加明確。

範例：


func Join(parts []string, sep string) string {
	var out string
	for i, p := range parts {
		if i > 0 {
			out += sep
		}
		out += p
	}
	return out
}

要修正程式碼，請使用將 string += string 取代為 strings.Builder 快速修復。

在套用快速修復後：


func Join(parts []string, sep string) string {
	var out strings.Builder
	for i, p := range parts {
		if i > 0 {
			out.WriteString(sep)
		}
		out.WriteString(p)
	}
	return out.String()
}
