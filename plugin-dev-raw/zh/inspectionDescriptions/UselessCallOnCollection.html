報告對標準庫中的集合、可迭代物件和序列的冗餘呼叫。

此檢查會檢測兩種類型的冗餘：

  • 對已篩選集合的冗餘 filter… 呼叫。 只有在類型不同於結果類型的接收者上調用時，filterNotNull() 或 filterIsInstance 這類函式才有意義。 在其他情況下，可以忽略此類別呼叫，因為結果將相同。
  • 冗餘的 mapNotNull 呼叫（及其變體）。 如果轉換結果已保證為非空類型，則 mapNotNull 冗餘。 在這種情況下，可以去掉 NotNull 後綴（例如 mapNotNull → map）。

可以通過快速修復來省略冗餘呼叫，或將其取代為更簡單的替代方案。

範例：


  fun test(list: List<String>) {
      val x = list.filterNotNull() // 可被簡化為 'list'
      val y = list.filterIsInstance<String>() // 可被簡化為 'list'
  }


  fun test(list: List<Int>) {
      val x = list.mapNotNull { it + 1 } // 可被取代為 'map'
  }
