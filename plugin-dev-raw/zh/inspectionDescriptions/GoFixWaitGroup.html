報告常見的使用 wg.Add(1) 的 WaitGroup 模式，啟動 goroutine，並推遲 wg.Done()。

在 Go 1.25 及更高版本中，(*sync.WaitGroup).Go(func()) 將這些步驟合併為一個呼叫。 這會將 goroutine 啟動和 WaitGroup 計數結合在一起，並減少樣板程式碼。

範例：


func Fanout(tasks []func()) {
	var wg sync.WaitGroup
	for _, task := range tasks {
		wg.Add(1)
		go func() {
			defer wg.Done()
			task()
		}()
	}
	wg.Wait()
}

要修正程式碼，請使用使用 WaitGroup.Go 進行簡化快速修復。

在套用快速修復後：


func Fanout(tasks []func()) {
	var wg sync.WaitGroup
	for _, task := range tasks {
		wg.Go(func() {
			task()
		})
	}
	wg.Wait()
}
