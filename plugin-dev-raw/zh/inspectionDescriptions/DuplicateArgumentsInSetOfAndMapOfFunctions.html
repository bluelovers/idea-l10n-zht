報告 set 工廠函式中重複的常數元素，map 工廠函式中重複的常數鍵。

set 工廠函式中的重複條目通常是無意的，可能表示存在錯誤或拼寫錯誤。 在 set 工廠函式中，重複的元素會被忽略，因為集合只能包含唯一元素。 在 map 工廠函式中，具有相同鍵的條目會覆蓋先前條目，並且僅保留與該鍵相關聯的最後一個值。

該檢查適用於以下 map 工廠函式：

  • mapOf()
  • mutableMapOf()
  • hashMapOf()
  • linkedMapOf()
  • sortedMapOf()

檢測到使用 to 運算符建立的條目的重複映射鍵。

該檢查適用於以下 set 工廠函式：

  • setOf()
  • mutableSetOf()
  • hashSetOf()
  • linkedSetOf()
  • sortedSetOf()

該檢查會報告其值可以求值為編譯時常量的實參，包括常數字面量和 const val 參照。

範例：


val numbers = setOf(1, 1, 2)

值 1 出現多次。 


val mapping = mapOf(
    1 to "first",
    1 to "second",
)

兩個條目使用同一個鍵。

具有 const val 的範例：


const val ID = 42

val ids = setOf(ID, 42)

兩個實參求值為同一個常量值。
