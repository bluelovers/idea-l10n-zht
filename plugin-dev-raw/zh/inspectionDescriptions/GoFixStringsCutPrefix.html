報告使用 strings.HasPrefix 檢查前綴，隨後又使用 strings.TrimPrefix 移除該前綴的程式碼。

此模式會對前綴進行兩次掃描。 strings.CutPrefix 會用一步移除前綴，並返回更新後的字串以及一個用於報告該前綴是否存在的布林值。

範例：


func Strip(s string) (string, bool) {
	if strings.HasPrefix(s, "v") {
		return strings.TrimPrefix(s, "v"), true
	}
	return s, false
}

要修正程式碼，請使用將 HasPrefix/TrimPrefix 取代為 CutPrefix 快速修復。

在套用快速修復後：


func Strip(s string) (string, bool) {
	if after, ok := strings.CutPrefix(s, "v"); ok {
		return after, true
	}
	return s, false
}
