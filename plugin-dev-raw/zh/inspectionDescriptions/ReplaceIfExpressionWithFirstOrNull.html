報告檢查列表、陣列或字串是否不為空後返回第一個元素或 null 的 if 表達式。

使用 firstOrNull() 可以使程式碼更簡潔、更符合慣用法。

該快速修復會將整個 if 表達式取代為 firstOrNull()。

範例：


  fun firstChild(children: List<String>): String？ {
      return if (children.isNotEmpty()) {
          children[0]
      } else {
          null
      }
  }

在套用快速修復後：


  fun firstChild(children: List<String>): String？ {
      return children.firstOrNull()
  }
