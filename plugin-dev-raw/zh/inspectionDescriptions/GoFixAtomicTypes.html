報告使用了可被取代為類型化原子值的原始 sync/atomic 函式，例如 atomic.AddInt64 和 atomic.LoadInt64。

atomic.Int64 等類型化原子值使原子存取成為欄位類型的一部分。 這有助於防止對同一值進行非原子存取，並避免 32 位平台上出現對齊問題。

範例：


type Counter struct {
	hits int64
}

func (c *Counter) Bump() {
	atomic.AddInt64(&c.hits, 1)
}

func (c *Counter) Read() int64 {
	return atomic.LoadInt64(&c.hits)
}

要修正程式碼，請使用將 int64 取代為 atomic.Int64 快速修復。

在套用快速修復後：


type Counter struct {
	hits atomic.Int64
}

func (c *Counter) Bump() {
	c.hits.Add(1)
}

func (c *Counter) Read() int64 {
	return c.hits.Load()
}
